# Digest: distribution resource planning software (distributor page, VOS is NOT DRP)

## 1. SERP makeup
8 usable scrapes (SAP help doc failed). 3 vendor landing pages (Acumatica ERP DRP module, Anaplan planning suite,
r4 AI "decision ops" page written like an article), 4 explainers/docs (NetSuite article, NetSuite help doc, SimplyDepo
blog, GeeksforGeeks) and 1 directory (Solutions Review distribution ERP list). Industries: manufacturing, CPG, retail,
multi-warehouse enterprise supply chain; SimplyDepo and the ERP directory are the only B2B-wholesale voices. Zero
foodservice or restaurant content. The searcher is a supply chain planner, an ERP shopper, or a student. VOS's buyer
(small independent food distributor) is a thin slice: the one who runs planning in an ERP or a spreadsheet and whose
input data is phone orders. Intent is far from VOS; the page wins only by being honest and useful about input data.

## 5. Where our page is weaker
- Hero: H1 says "clean orders" (vague); lead opens on the negative before any outcome.
- Stats: "Every / order logged with who placed it and when" nearly mirrors order-tracking's stat; says nothing about accuracy.
- Features H2 "what ... is missing" is presumptuous; the page's own question is "what does it run on".
- Feature 2 body lists formats again (hero trust, card, FAQ 4 already do); "Every line tied to one of your SKUs" repeats body and card.
- Accuracy gap: "No re-keying" and FAQ 4 "Nobody re-types it" are only true for EDI, API, QuickBooks, not emailed PDFs.
- Repeats: "plan pickers and trucks", "orders arrive by", "orders flow into", "24/7 order intake", "per-account catalogs",
  "no system replacement" x2, "your plan starts", "system you already" all appear twice.
- Final CTA trust says "Your ERP stays in place" and "No system replacement needed": the same point twice.

## 6. Where VOS genuinely differs
- The category sells the plan; VOS supplies the input the plan is built on. Lean on "plan is only as good as its data".
- Actual orders arrive the night before, 24/7 and by voice, so demand is known before the morning plan (not a forecast).
- Customers confirm each order before sending, so quantities are what they meant (data accuracy, the SERP's stated weak spot).
- Live in 24 to 48 hours with no IT project vs month-long planning suite projects; built for small to mid-size food distributors.
- Additive: keeps the ERP, planning tool and routes. Say it once, clearly, not three times.
